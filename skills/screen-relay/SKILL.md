# screen-relay

## Start here

Load the current workflow from the installed CLI:

```sh
screen-relay skills get core
screen-relay skills get core --full
```

Load specialized guidance when needed:

```sh
screen-relay skills get remote-host
```

List available skills with `screen-relay skills list`.
